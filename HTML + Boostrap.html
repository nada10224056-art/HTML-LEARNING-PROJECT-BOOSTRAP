1. What is HTML?

HTML (HyperText Markup Language) adalah fondasi utama dari setiap situs web. Tag HTML memberi tahu peramban web bagaimana struktur konten harus ditampilkan.

Keunggulan HTML

Standard Language

Standard Language

Document Structure

Document Structure

Menata kerangka teks, gambar, tabel, dan media menjadi layout yang rapi.

Element Series

Element Series

Terdiri dari susunan elemen (tag) seperti paragraf, judul, dan tombol.

2. Basic HTML Structure

Struktur Dasar HTML

  • <!DOCTYPE html> Mendeklarasikan bahwa dokumen menggunakan standar HTML5.
  • <html> Elemen utama (root) pembungkus seluruh elemen di dalam halaman web.
  • <head> Tempat menyimpan metadata, judul, dan pemanggilan file stylesheet.
  • <body> Area utama yang memuat seluruh elemen visual yang dilihat pengguna.

3. Essential HTML Tags

Daftar Tag HTML

Tag Deskripsi Contoh Sintaks
<h1> - <h6> Menentukan tingkat hirarki judul/heading. <h1>Heading Utama</h1>
<p> Membuat blok teks berupa paragraf. <p>Teks paragraf.</p>
<a> Membuat tautan/hyperlink menuju halaman lain. <a href="url">Klik di sini</a>
<img> Menampilkan file gambar pada halaman. <img src="foto.jpg" alt="Foto">
<ul> / <ol> Membuat daftar poin (unordered) atau angka (ordered). <ul><li>Item</li></ul>
